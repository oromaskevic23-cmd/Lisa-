# Contributing to LISA

Contributions must be in English and focus on verifiable, permissioned improvements.

1. Open a narrowly scoped issue explaining the intended change and expected evidence.
2. Do not change token identity, canonical contract reference, founding attribution or the fox emblem without explicit owner approval.
3. Include reproducible checks for changes to scripts, workflows, hashes, or token claims.
4. Do not introduce keys, signing routines, paid dependencies, tracking, mass outreach, exchange promises, or personal data.
5. Respect external code licenses, source attribution, contributor rights and the Public/Private Boundary.
6. Do not label a draft, demo, proposal or locally passing test as a production release.

Submission does not guarantee acceptance or a license for commercial use. Licensing and contributor terms require separate owner review.
