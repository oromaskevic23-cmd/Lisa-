## Evidence gates before market claims

1. Confirm chain ID, deployment bytecode and token parameters at a numbered block with reproducible JSON-RPC observations.
2. Inspect and independently review the precise verified contract source, admin privileges, mint/burn/transfer behavior and upgrades.
3. Verify total and circulating supply, relevant wallets, allocations, vesting and treasury custody.
4. Independently check existing market liquidity, holders, actual execution, and any venue admission.
5. Obtain appropriate legal assessment and permission for each jurisdiction-specific public action.

**Unverified:** current balance, supply, liquidity, volume, token price, holder count, exchanges, completed independent audit and future profitability.

Do not confuse source code matching with third-party security auditing, and never infer a listing from a blockchain explorer page.
