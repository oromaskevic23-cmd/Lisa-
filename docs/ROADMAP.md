# LISA — Evidence-Gated Development Roadmap

**Current scope:** public branding, English documentation and repeatable presentation-integrity checks.

| Gate | Engineering deliverable | Evidence needed |
| --- | --- | --- |
| 1. Identity | Original fox logo, owner-provided Polygon reference, canonical English presentation | SHA-256 and validated asset link |
| 2. On-chain diligence | Read-only contract inspection | Repeatable block-specific observations |
| 3. Contract assessment | Controls, supply and transfer-risk analysis | Independent security review and documented issues |
| 4. Community foundation | Genuine opt-in channels and communication standards | Auditable, consent-based activity |
| 5. Optional utility design | Bounded use-case specifications | Independent engineering review and sandbox tests |
| 6. Optional integration | Approval-gated, non-custodial testnet prototype | Zero Trust, QA, authorization and rollback evidence |
| 7. Optional venue evaluation | Verified dossier and eligibility review | Counsel-reviewed disclosures and independent venue decision |

Each future stage is subject to owner authorization, applicable law, actual market demand, security review and available resources. **No exchange listing, commercial partnership, market price, audience size or deadline is promised.**

**FREE_ONLY** applies to unapproved engineering activity; no wallet spending, API purchases, or paid infrastructure may be implied by this roadmap.
